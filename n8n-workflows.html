n8n Workflows: Article Sync to Google Sheets

Two workflows configured for different times of day (7 AM and 12 PM, America/Argentina/Buenos_Aires)

Setup Instructions:

  1. Copy the JSON for each workflow (buttons below)
  2. In n8n, click "Import from URL or JSON"
  3. Paste the JSON and import
  4. Replace the placeholders:
    • SUPABASE_API_KEY — Get from Supabase dashboard (Settings → API → anon/public key)
    • GOOGLE_SHEETS_SPREADSHEET_ID — From the Google Sheets URL
    • GOOGLE_SHEETS_SHEET_NAME — The exact sheet tab name
  5. Test and activate both workflows
